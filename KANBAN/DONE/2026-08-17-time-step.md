### 实现的功能

1. **模拟时钟**: `TickEngine` 管理 tick 从 0 开始递增
2. **7 阶段执行器**:
   - Freeze: 冻结全局状态快照
   - Deliver: 投递满足条件的邮件
   - Observe: Agent 从快照读取输入
   - Decide: Agent 生成动作计划（可扩展的回调接口）
   - Act: 并行执行动作
   - Commit: 原子提交（邮件入队等）
   - Audit: 记录审计事件
3. **快照机制**: 每个 tick 创建独立快照，保证读一致性（§13.1）
4. **暂停/恢复**: 支持 `pause()` / `resume()`（§12.1, §12.2）
5. **邮件投递**: 按 `deliver_at_tick` 准时投递
6. **可扩展性**: `register_phase_handler()` 允许覆盖任意阶段
7. **历史记录**: `history` 属性保存所有 tick 执行结果

### 验收标准

- [x] tick 从 0 开始递增
- [x] 每个时间步严格按 7 阶段执行
- [x] 快照确保所有 Agent 看到同一版本状态
- [x] 已完成时间步不可被修改
