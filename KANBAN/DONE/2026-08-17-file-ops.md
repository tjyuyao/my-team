### 实现的功能

1. **read**: 读取 Agent 私人空间内的文件，返回内容
2. **write**: 写入文件，自动创建父目录，支持覆盖
3. **ls**: 列出目录内容，返回文件名、类型、大小
4. **权限检查**: 所有操作经过 `PrivateStore.resolve_path()` 验证
5. **大小限制**: 单步写入大小限制（默认 10MB）
6. **存储配额**: Agent 总存储量限制（默认 512MB）
7. **审计日志**: 所有操作记录到 `FileOpsAuditLog`（agent_id, operation, path, success, tick）
