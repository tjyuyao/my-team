## Executive Summary

v0.3.0 addresses the **3 P1 correctness/security blockers** identified in the v0.2.0 code review:

1. **Lock Token Mechanism** — UUID4 tokens prevent stale-holder attacks
2. **Typed AgentSnapshot** — frozen dataclass replaces raw `dict` in `observe()`
3. **Transaction Boundary Clarification** — side_effect classification, outbox pattern, rollback clears outbox

These were the highest-priority items from the 26-issue review, blocking claims of "reliable concurrent access" and "secure identity binding."

**Recommended label:** `v0.3.0 — P1 Correctness Fixes`

## What Changed

### P1-1: Lock Token Mechanism

**Problem:** `release(resource, agent_id)` only checked owner, not a unique token. Stale-holder attack: Agent A acquires → lease expires → Agent B acquires → Agent A's delayed `release()` removes B's lock.

**Changes:**
- `LockInfo` gains `lock_token: str` field (UUID4 hex, auto-generated)
- `LockManager.release()` requires `lock_token` parameter, raises `LockTokenError` on mismatch
- `LockManager.renew()` requires `lock_token` parameter, raises `LockTokenError` on mismatch
- `LockManager.acquire()` returns `LockInfo` with token (no change needed)
- Snapshot includes `lock_token` for agent use
- New `LockTokenError` exception class

**Files modified:** `shared_kb.py`, `simulation.py`, `test_shared_kb.py`
**New tests:** 3 (stale-holder prevention, token mismatch release/renew)

### P1-2: Typed AgentSnapshot

**Problem:** `observe(snapshot: dict)` was untyped — agents could read any key, schema was undocumented, type checking couldn't catch errors.

**Changes:**
- New `AgentSnapshot` frozen dataclass with typed fields:
  - `tick: int`
  - `emails: tuple[dict[str, Any], ...]`
  - `task_states: dict[str, dict[str, Any]]`
  - `shared_kb_snapshot: dict[str, Any]`
  - `lock_states: dict[str, Any]`
  - `private_workspace_path: str`
- `AgentRuntime.observe()` protocol: `dict[str, Any]` → `AgentSnapshot`
- `BaseAgent.observe()`: attribute access instead of `.get()`
- `Simulation._phase_observe()`: constructs `AgentSnapshot` instead of raw dict

**Files modified:** `agent_runtime.py`, `simulation.py`, `test_agent_runtime.py`
**New tests:** 5 (immutability, defaults, equality, inequality, tuple emails)

### P1-3: Transaction Boundary Clarification

**Problem:** `commit()` only changed status fields, no distinction between in-memory and external effects, no outbox for side effects, rollback didn't clear outbox.

**Changes:**
- `StagedEffect` gains `side_effect: bool` field, auto-classified by `EffectType`
- `_EXTERNAL_EFFECT_TYPES` constant: `EMAIL_SEND, EMAIL_DELIVER, FILE_WRITE, FILE_DELETE`
- `TransactionBuffer` gains `_outbox` list for side effects
- `commit()` populates outbox with side effects
- `rollback()` clears outbox (side effects discarded)
- New methods: `get_outbox()`, `clear_outbox()`, `outbox_count`
- `TRANSACTION_ROLLBACK` audit event type added

**Files modified:** `transaction.py`, `audit.py`
**New file:** `test_transaction_rollback.py` (16 tests)
