## v0.14.0 交付内容

### 设计修订门（前置）

- `device-private-home-correction`：设备实现位于设备 identity 私家；按设备
  限定的维护者卸载→编辑→重载会话；移除共享 `data/devices`、
  `INSTANCE=per-agent`、`bound_agent`、`device-id@agent-id`
  （提交 a0f99fd 收尾）。

### 卡片交付

| 卡 | 关键提交 |
|---|---|
| data-dir-convention | 数据区 `data/<identity>` 约定 + identity 防路径逃逸校验 + 装载时创建（8756fad/5b9e05d） |
| sandbox-wrapper | bwrap 重执行固定矩阵（只读系统 / 数据区唯一写根 / 默认禁网 / setrlimit / userns+pidns+netns+ipcns）+ 传输层换 fd 继承 Connection（沙箱内零共享 IPC）+ 宿主读侧盖章；outbound-channel 收编并入（b83bda6/2c8c3f8） |
| unified-identity-home | 统一身份模型：agent/device 都是 user 各有家 + 挂载矩阵按类型 + data 根 tmpfs 掩蔽（d65d36c/b5c58fd） |
| network-declaration | `needs_network` 显式声明通道（沙箱控制字段不进 Device 构造参数）（13ec5fe） |
| bash-sandbox-adapt | bash 设备沙箱语义（矩阵加 `--dev`；`MY_TEAM_DATA_DIR` 注入；cwd 落 bash 家；setsid 逃逸由 pidns+`--die-with-parent` 收敛）（1da81de） |
| sandbox-verification | `check_sandbox_verification` 收口（pidns 防杀兄弟 / ipcns 隔离 / per-position 矩阵一致 / 伪造 source 盖章覆盖 / 重装旧通道不残留）+ AUTHORITY.md §8 覆盖 + 全量回归（b7acc70） |

### 范围外独立提交

  返回 VOID 由 BucketDispatcher 自动生成回执事件路由回 source；不标记零
  开销。非 v0.14 卡片，归 v0.15 编排。

## 已知限制

1. 设备间调用与 origin（AUTHORITY.md 开放问题 11）未做。
2. 运行期状态持久化（开放问题 7）未做。
3. 服务账户 Agent、凭证管理（信任触发条件驱动的未来项）未做。
4. 三态重构后活动测试面收缩（14 测试），combined 覆盖率 62.66% 未达
   `fail_under=70`；覆盖基数归零起步，需 v0.15 补齐 kernel 关键路径测试。

   时间 1.8s，真实开销集中在进程拉起与沙箱子进程。
