# v0.13.0 计划 — 沙箱脚本执行器（bash）

**Date:** 2026-08-24
**Status:** 计划中（v0.12 门通过后启动）

## 版本定位

受限执行器族从"受限 python 模组"扩展到 **bash 脚本**，二者运行于
**同一 T16a 真实沙箱**（unprivileged userns + netns + 只读挂载 +
rlimit + 环境净化）。这是 v1.0 前必做：软件公司等场景离开 shell
（git/构建/CLI 生态）能力受限；沙箱是二进制无关的（run_tests 已
在跑任意 pytest 代码），bash 只是被同样禁锢的另一个二进制。

```text
v0.13 — 沙箱脚本执行器（受限执行器族 = python 模组 + bash 脚本）
```

## 范围

- **脚本执行模型**：`bash -c <script>` 批处理（非交互），命令 +
  输入快照 + 输出入 Journal；effect = staged 文件变更 + stdout
  （与 run_tests 同模式）；
- **复用 T16a 沙箱**：无新增安全面（网络真拒/只读真生效已有非自证
  测试）；平台条件（unprivileged userns 可用性）沿用 applied=false
  + skip 语义；
- **长驻会话复用**：高频命令摊销沙箱启动成本（v1 可先每调用一脚本，
  会话复用 v1.1 上）；
- **max_processes 声明约束**：RLIMIT_NPROC 为用户级计数（v0.10
  已知限制），bash 多子进程脚本须声明进程数上限；精确解（cgroup）
  后续；
- **工具制造整合**：私有工具条目（type=tool）的 content 可含 bash
  脚本（与 python 模组平权，SPEC §4.2 记忆条目）；Agent 经 `(device,
  capability)` 授权获得；
- 权限：deny-by-default + 安装审计照旧；执行器分级
  SANDBOXED_PROCESS。

## 依赖

- v0.12（真实 LLM API）之后、v1.0 之前；
- 复用 v0.11 N1a 设备协议与 Authority（设备协议无改动，bash 是内核沙箱真理的
  执行器实例）。

## 验收标准

- [ ] bash 脚本在真实沙箱执行：网络真拒、根只读、工作区可写
      （非自证测试）
- [ ] 每调用一脚本路径全绿；会话复用性能基准（vs 每调用）记录
- [ ] 多子进程脚本受 max_processes 约束（不误伤宿主）
- [ ] 审计：命令/快照/输出入 Journal；effect 可回滚
- [ ] Agent 可制造并调用含 bash 脚本的私有工具
- [ ] `uv run pytest -q` 全绿；ruff/mypy 通过
