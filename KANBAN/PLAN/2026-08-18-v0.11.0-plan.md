## 版本定位

v0.11 的核心交付是**扩展表面 P0 语义闭合**（ProcessDef/Authority/
Recovery/ExecutionProfile/Trust Boundary/Predicate/Validator，见
`2026-08-18-extension-surface-plan.md`）；五场景包、Skill 等场景资产
在语义闭合后交付，且受测试向量纪律约束。

```text
v0.11 — 扩展表面 P0 语义闭合（核心）
        + 场景包/Skill（依赖语义闭合，延后）
        + v0.8 遗留收尾 / MCP 接入（可并行）
```

## 与扩展表面的关系

扩展表面是**跨版本架构线**（v0.11→v1.0+，P1 自进化、P2 多 Deployment
等属 v1.0+），其实现路线图独立成文（extension-surface-plan.md）；
本文件只列 v0.11 版本内要交付的 TODO 及其 gate。两条硬约束（来自
扩展表面全面审阅）：

1. **场景 = 测试向量，不是设计输入**：最小测试向量
   `IngressEvent → ProcessInstance → assignment → human approval →
   external irreversible op → crash recovery → compensation/reconciliation`
   闭合前，不实现任何场景资产（五场景包、Skill 示例）。
2. 场景包 = **配置包**（Org/Role/ProcessDef/Authority/Schedule/KPI），
   可执行能力（handler/scripts）由 Provider 能力包提供；二者不在同一
   安装信任域（审阅 P0-6）。
