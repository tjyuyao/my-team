## 待重划项（与扩展表面方向冲突，须先改 TODO 再实现）

- **T9 ingress-egress**：当前设计把 IngressEvent 直接转 WakeEvent/
  TaskCreate/Record/Email；扩展表面要求前门为
  `IngressEvent → ProcessInstance`（最小测试向量）。transport/去重/ack
  部分方向中立可先做，映射层待 process-model 落地。
- **T12 approval-and-human-worker**：当前 `HUMAN_APPROVAL` pending op
  模型过时；须统一为 HumanTask（work/approval/decision/consultation）
  并按三查分离（Capability / Authority / Gate）设计；human 身份须经
  认证（Identity 闭包）；"升级"改用结构化 escalation（on/mode/target）。
- **T11 scheduler**（小改）：升级阶梯"通知 Manager → 转人工 → 关闭"
  与 escalation 模型不一致，措辞改为引用结构化升级。
- **SPEC 对齐**：§8.1 Ingress、§10.2 ApprovalGate 先行对齐上述方向，
  再改 TODO（避免 TODO 与 SPEC 继续互相矛盾）。
