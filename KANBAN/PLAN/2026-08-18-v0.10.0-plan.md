## 重划结果（2026-08-18，SPEC 对齐后）

本版本"待重划"项已全部收敛，卡片与 SPEC 不再互相矛盾：

- **T9 ingress-egress**：收敛为传输层（IngressBuffer / 去重 / ack /
  Integration 注册 / 出站 pending op）。映射前门 `IngressEvent →
  ProcessInstance` 并入 v0.11 E1（process-model 最小测试向量首段）；
  SPEC §8.1 已对齐。卡片已重写（去掉映射层要求与"创建任务"验收项）。
- **T12 approval-and-human-worker**：拆为 `T12a human-worker`（kind=human
  Agent）与 `T12b credential-store` 两卡，留在 v0.10；ApprovalGate
  （HumanTask 模型 + 三查分离）并入 v0.11 E1/E2，本版本不再列卡。
  SPEC §10.2 已对齐（HUMAN_APPROVAL pending op 废止，统一 HumanTask）。
- **T11 scheduler**：升级措辞已按结构化 escalation 订正（卡 + SPEC §9.2）。
- **Identity 闭包**：Human Worker 的完整身份认证（from/to 注入、不可伪造）
  依赖 SPEC §12.1，已记入 v0.11 P1 backlog；v0.10 最小实现以 org-tree
  `agent_id` 为身份，不伪造字段（见 T12a 注记）。
