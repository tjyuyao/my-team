## 版本定位

v0.11 的核心交付是**扩展表面 P0 语义闭合**。2026-08-24 架构坍缩 +
Agent 模型收敛后范围：**ProcessDef/ProcessInstance 废弃**（流程 =
业务语言 SOP 知识，SPEC §1.8）；三态内核（真理/设备/Agent，SPEC
§1.7）；**岗位模型**（Position：JD/边/授权，岗人分离，经手物归岗，
组织架构设备）；**记忆与注入系统**（条目/召回/工作记忆/整理模式）；
设备化与单层授权（`(device, capability)`）。五场景包、Skill 等场景
资产在语义闭合后交付，且受测试向量纪律约束（设计规范见
`OPEN_ISSUE/2026-08-24-extension-surface-spec.md`；其「编排层」
一节已加坍缩+三态收敛注记，正文为历史讨论）。

```text
v0.11 — 扩展表面 P0 语义闭合（三态收敛，9 项待重新分解）
        + 场景包/Skill（依赖语义闭合，延后）
        + T17 MCP（可并行）
v0.12 — 真实 LLM API 接入验证（llm_gateway 对接真实供应商）
v0.13 — 沙箱脚本执行器（bash，v1.0 前必做）
```

扩展表面是跨版本方向：P0 = 本版本核心交付；P1/P2（自进化风险分级、
多 Deployment、embedding 等）属 v1.0+，列于下文 backlog，待 v1.0 计划
出现时落位。

## 最小测试向量（贯穿所有任务的唯一判据）

```text
IngressEvent → Task 分解（岗位 + SOP 知识）→ human approval（HumanTask）
→ external irreversible operation → crash recovery
→ compensation / reconciliation
```

这条链路在语义上闭合之前，不实现任何场景资产（软件公司/小说工作室/电商/
自媒体/知识星球）。

  - [ ] 任一任务/决策记录其生效的知识与策略版本快照（可重放、可审计"当时知道什么"）
  - [ ] 新 PackageVersion 发布不改变运行中任务的版本绑定
  - [ ] Commit 成功但 Publish 未完成时，重启后可恢复 outbox（稳定幂等键）
  - [ ] 外部调用结果为 `unknown` 时，未经确认不重复执行不可逆操作
  - [ ] 任意审批任务/未决效果都有终止路径或显式 escalation
  - [ ] 任意 predicate 纯、有限、可审计、可重放
  - [ ] root 不能扩大自身 authorization，不能绕过 Owner escalation
  - [ ] 未如实申报的可执行条目加载即拒；任一能力安装可审计追溯到
        installer/hash/能力声明（审计制，2026-08-24）
  - [ ] 同 Deployment 内私有记忆/凭证/资产引用不交叉泄漏
  - [ ] 角色变化不伪造/覆盖 Principal Identity
  - [ ] 外部事件重复投递不创建重复 Task/意图（除非显式声明允许）
  - [ ] 任一 effect 可追溯到 Intent、Task、PackageVersion、Principal
  - [ ] 最小测试向量端到端闭合，内核代码零改动
