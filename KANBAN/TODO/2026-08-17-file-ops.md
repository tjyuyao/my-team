# read/write/ls 基本工具

**Phase:** 1 - 基础运行时
**Source:** SPEC §4.1, §4.2, §4.3

## 目标

实现 Agent 可使用的基础文件操作工具。

## 工具列表

| 工具 | 说明 | Root Agent | 子 Agent |
|------|------|------------|----------|
| read | 读取文件 | ✓ | ✓ |
| write | 写入文件 | ✓ | ✓ |
| ls | 列出目录 | ✓ | ✓ |

## 约束

- Root Agent 的 `delegate` 不是普通文件系统工具，而是系统控制能力
- 工具调用必须经过权限检查
- 工具调用结果必须写入审计日志
- 单步写入大小有限制
- 单个 Agent 总存储量有限制

## 产出

- read/write/ls 工具实现
- 权限检查中间件
- 审计日志记录

## 验收标准

- [ ] Agent 能读写自己空间内的文件
- [ ] 越权访问被拒绝并记录审计事件
- [ ] 所有工具调用产生审计日志
