# 共享知识库初始化

**Phase:** 3 - 共享知识库
**Source:** SPEC §6.1

## 目标

实现团队共享的知识库存储。

## 目录结构

```text
/shared-kb/
  project/
    requirements/
    research/
    planning/
    decisions/
    deliverables/
  reference/
  templates/
  archive/
```

## 特性

- 可被多个 Agent 访问
- 受路径级和操作级权限控制
- 支持锁定、修改、提交和审计
- 不属于任何单个 Agent

## 产出

- 共享知识库目录初始化
- 基础读写 API
- 文件元数据（版本号、最后修改者、最后修改时间）

## 验收标准

- [ ] 创建模拟时自动生成共享知识库目录
- [ ] 文件具有版本号等元数据
- [ ] 能正确读写共享文件
