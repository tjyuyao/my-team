# 修改时间步长

**Phase:** 4 - 人类控制
**Source:** SPEC §12.3

## 目标

实现运行时调整时间步长的功能。

## 两种模式

### 即时调整
从下一个时间步开始使用新步长。

### 计划调整
从指定时间步开始使用新步长。

```json
{
  "command": "set_tick_duration",
  "value": 30,
  "unit": "seconds",
  "effective_tick": 25
}
```

## 约束

- 不修改已完成的时间步
- 不回溯重放正在执行的时间步

## 产出

- 步长调整 API
- 调度器适配
- 调整审计

## 验收标准

- [ ] 即时调整从下一 tick 生效
- [ ] 计划调整从指定 tick 生效
- [ ] 调整事件写入审计日志
