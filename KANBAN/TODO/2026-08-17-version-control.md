# 版本控制

**Phase:** 3 - 共享知识库
**Source:** SPEC §6.3

## 目标

为共享知识库中的文件实现版本控制。

## 版本元数据

```json
{
  "path": "project/research/market-report.md",
  "version": 7,
  "last_modified_by": "agent.research",
  "last_modified_at_tick": 15
}
```

## 提交模型

```text
获取锁 → 读取当前版本 → 修改本地副本 → 写入新版本
→ 执行一致性检查 → 提交版本 → 释放锁
```

## 冲突检测

- 提交时必须携带读取时的版本号
- 版本号不匹配则提交失败
- 需重新读取和合并

## 产出

- 版本号管理
- 乐观锁提交
- 版本历史记录

## 验收标准

- [ ] 每次写入自动递增版本号
- [ ] 版本号不匹配时拒绝提交
- [ ] 能查询文件的版本历史
