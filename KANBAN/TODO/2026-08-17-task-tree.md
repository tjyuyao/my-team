# 任务树管理

**Phase:** 2 - E-mail 协作
**Source:** SPEC §4.4, §11.2

## 目标

实现动态任务树的创建、状态跟踪和管理。

## 任务状态

```text
draft → assigned → accepted → in_progress → submitted → reviewing → completed
                           ↘ blocked      ↘ waiting_for_children
                           ↘ failed       ↘ cancelled
                                           ↘ expired
```

## 任务属性

- task_id: 唯一标识
- title / description: 任务描述
- creator_agent_id / owner_agent_id: 创建者与执行者
- parent_task_id: 父任务
- status / priority: 状态与优先级
- deadline_tick: 截止时间
- required_outputs: 预期产出
- created_at_tick / updated_at_tick: 时间戳

## 产出

- 任务 CRUD API
- 状态转换逻辑
- 任务树遍历（查找子任务、父任务）
- 截止时间检查

## 验收标准

- [ ] 能创建带层级关系的任务树
- [ ] 任务状态按规则转换
- [ ] 过期任务自动标记为 expired
- [ ] 任务树遍历正确返回父子关系
