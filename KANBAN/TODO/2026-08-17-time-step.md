# 时间步推进机制

**Phase:** 1 - 基础运行时
**Source:** SPEC §8.1, §8.2

## 目标

实现离散时间步驱动的模拟时钟和推进机制。

## 时间步阶段

```text
Phase 1: Freeze    - 冻结全局状态快照
Phase 2: Deliver   - 投递满足条件的邮件
Phase 3: Observe   - Agent 读取输入
Phase 4: Decide    - Agent 生成动作计划
Phase 5: Act       - 并行执行动作
Phase 6: Commit    - 统一提交动作
Phase 7: Audit     - 记录审计事件
```

## 配置

```json
{
  "tick_duration": { "value": 10, "unit": "seconds" },
  "simulation_time_per_tick": { "value": 1, "unit": "hour" },
  "mode": "realtime"
}
```

## 产出

- 模拟时钟
- 7 阶段推进器
- 快照机制
- 配置加载

## 验收标准

- [ ] tick 从 0 开始递增
- [ ] 每个时间步严格按 7 阶段执行
- [ ] 快照确保所有 Agent 看到同一版本状态
- [ ] 已完成时间步不可被修改
