# 邮箱系统

**Phase:** 2 - E-mail 协作
**Source:** SPEC §4.5, §5.1

## 目标

实现每个 Agent 的 inbox/outbox 邮箱系统。

## 邮箱结构

```text
/private/agent.{id}/
  inbox/        # 收件箱 - 系统投递的邮件
  outbox/       # 发件箱 - Agent 发出的邮件
```

## 邮件属性

- email_id: 唯一标识
- thread_id: 邮件线程
- from / to / cc: 发送方与接收方
- email_type: 邮件类型（13 种）
- task_id: 关联任务
- deliver_at_tick: 投递时间
- status: queued / delivered / read
- priority: 优先级
- requires_reply: 是否需要回复

## 产出

- 邮箱存储实现
- 邮件投递逻辑
- 邮件排序规则

## 验收标准

- [ ] 邮件正确投递到目标 Agent 的 inbox
- [ ] 邮件排序按规范执行
- [ ] 邮件状态正确更新
